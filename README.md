# HardTech - Site Institucional

Site institucional da HardTech, empresa de suporte de equipamentos e balanças comerciais em Curitiba - PR.

## Conteúdo

- Landing page em HTML/CSS/JS puro (sem dependências)
- Logo recriada em SVG vetorial (`assets/logo.svg`)
- Seções: Serviços, Produtos, Sobre, Contato
- Botões diretos para WhatsApp Comercial e Automação
- Formulário de orçamento que redireciona para o WhatsApp

## Como visualizar localmente

Basta abrir o arquivo `index.html` no navegador, ou rodar um servidor local:

```bash
npx serve .
```

## Publicar no GitHub Pages

1. Faça push deste repositório para o GitHub
2. Nas configurações do repositório, vá em **Pages**
3. Selecione a branch `main` e a pasta raiz (`/`)
4. O site ficará disponível em `https://<usuario>.github.io/<repositorio>/`
